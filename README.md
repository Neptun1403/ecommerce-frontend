# E-Commerce Frontend

A React-based frontend for the E-Commerce platform.

## Technologies
- React.js
- React Router DOM
- Axios
- Context API

## Features
- User login and registration
- Product listing with search
- Shopping cart
- Admin panel (add, edit, delete products)

## Installation

1. Clone the repository:
git clone https://github.com/Neptun1403/ecommerce-frontend.git

2. Install dependencies:
npm install

3. Start the app:
npm start

## Pages
- `/` — Products page
- `/login` — Login page
- `/register` — Register page
- `/cart` — Cart page
- `/admin` — Admin panel (admin only)

## Backend
This frontend works with the E-Commerce API:
https://github.com/Neptun1403/ecommerce-api
